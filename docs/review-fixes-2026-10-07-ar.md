## استخدام العمل دون اتصال

يفتح الموظف المهمة ويبدأ العمل أثناء الاتصال حتى يحضّر المتصفح بطاقة تلك الجولة. بعدها يستطيع كتابة النتيجة واختيار الصور وحفظها عند الانقطاع، وإعادة فتح صفحة المهمة ومراجعة ما حفظه. افتح النظام بالحساب نفسه عند عودة الاتصال؛ لا يُضمن الرفع والمتصفح مغلق. لا تُعرض النتيجة للمراجعة على الخادم قبل نجاح المزامنة. تغيير الإسناد أو الجولة يوقف الرفع للمراجعة بدل ضياع النص والصور.

تظل إجراءات الإسناد والإحالة واعتماد الرسوم وتأكيد الدفع والإغلاق النهائي بحاجة إلى اتصال والتحقق من الحالة الحالية. لا يُخزن HTML الموظفين أو رموز الجلسات أو ردود API في CacheStorage. تُحفظ بطاقات التنفيذ ونتائجها الخاصة في IndexedDB على الجهاز للحساب الذي حضّرها. حذف بيانات المتصفح يفقد العناصر غير المرسلة. [تفاصيل التنفيذ والصور دون اتصال](offline-execution-results-ar.md).

## التحقق المنفذ

- اجتاز الاختبار المجمع138 اختبار Django، وفحص الترحيلات دون تغييرات، وفحص إعدادات التطبيق.
- اجتاز مسار سبعة بلاغات حتى الإغلاق وثلاث مخالفات بأنشطتها المنزلي والتجاري والحكومي، مع70 محاولة غير مسموحة. شمل البلاغ المالي الإسناد من مسؤول المالية، وعودة البلاغ الفني والمالي لمعالجة جديدة، والصور في كل جولة.
- اجتازت اختبارات المتصفح المتخصصة حفظ نتيجة وصورة أثناء الانقطاع وإعادة فتح المهمة، وفقد رد الاستلام دون تكرار، وتغيير الإسناد أثناء الانقطاع، وفصل المستفيد عن صور التنفيذ. نجحت فلاتر التقارير واستيراد النموذج ومعاينته واعتماده وحفظ نتائجه.
- اجتازت اختبارات التشغيل استعادة نسخة قاعدة ومستند ومرفق إلى قاعدة جديدة، ورفض الأرشيف المعدّل، وخدمة الإنتاج المحلية وضوابط المضيف وHTTPS.
- أُعيد اختبار المشغّل المحمول في Linux باستخدام PostgreSQL وWaitress الحقيقيين: ست مجموعات متصفح، والتشغيل والإيقاف وإعادة التشغيل والنسخ والاستعادة والقفل، واختبارات التعافي المخصصة. يمنع البناء استخدام نتيجة تخص مصدر تطبيق أو مشغّل مختلف، وتُضمّن نتيجة التحقق في الحزمة.

النتائج التفصيلية محفوظة في `test-results/` الخاص، وتقارير المشغّل في `test-results/windows-portable-validation/`. لا تحتوي Git على بيانات الاختبار أو لقطات قواعده. الاختبارات تثبت الحالات المنفذة؛ لم يُختبر حمل المؤسسة أو هاتف Android فعليًا.

## الحزمة وحدود التجربة

الحزمة الحالية `test-results/wash-windows-portable.zip` تتضمن `Start.cmd` و`Stop.cmd` و`Backup.cmd` و`Restore.cmd` ودليلًا عربيًا. راجع [تعليمات Windows](windows-portable-ar.md) خصوصًا حفظ الإعدادات واستعادة النسخة الكاملة إلى مجلد جديد.

**لم تُشغّل ملفات Windows الأصلية على جهاز Windows في هذه البيئة Linux.** تبقى تجربة Start على Windows 10/11 x64 وسياسات جهاز المؤسسة مطلوبة عند الاستلام؛ فحص ملفات PE وDLL لا يعادل التشغيل الأصلي. النسخة محلية على الكمبيوتر نفسه، ولا تمنح الهاتف رابط إنترنت. الاستضافة العامة تحتاج بيئة HTTPS مستقلة، ولم تُفعّل هنا.
