عن هذا الدليل

مرجع عملي لتقديم النظام للجنة، ثم تنفيذ تجربة منظمة بكل دور وظيفي.

تخدم بوابة مياه مأرب مسارين داخل نظام واحد: بلاغات المستفيدين لمتابعة الخدمة، والمخالفات الميدانية لتوثيق الضبط والإحالات والتسوية. يُسجل كل إجراء باسم صاحبه، وتبقى صلاحية الإغلاق النهائي للمدير الفني.

كيف تقرأ الدليل؟

  1. ١
    ابدأ بالصورة العامة

    راجع الأدوار ومسار البلاغ، ثم شغّل النسخة التجريبية واستخدم دليل تبديل الأدوار.

  2. ٢
    نفّذ الإجراء كما يظهر على الشاشة

    اسم الزر في النص مطابق للواجهة. الصور توضح الحالة التي يسبقها الإجراء، ولا تتضمن حسابات أو بيانات حقيقية.

  3. ٣
    تحقق من النتيجة

    راقب رقم الملف وحالته وسجل الإجراءات. في آخر الدليل قائمة اختبار للجنة وملاحظات لتوثيق التقييم.

01

من يستخدم النظام؟

لكل موظف حساب شخصي ودور محدد. بوابة المستفيدين منفصلة عن مساحة الموظفين.

الدورماذا يفعل؟القرار أو المخرج
المستفيديسجل بلاغه ويتابع بلاغاته فقط.رقم بلاغ وحالة يمكن متابعتها.
المدير الفنييسند العمل الفني، ويعيد الإسناد، ويراجع النتائج، ويدير الحسابات والنماذج.إغلاق البلاغ والمخالفة بعد استيفاء شروطهما.
الفنيينفذ المهام المسندة، ويكتب النتيجة ويرفق الصور، ويسجل المخالفات الميدانية.نتيجة تنتظر المراجعة؛ لا يغلق الملف.
مسؤول النظاميراجع المخالفة الواردة ويحولها إلى السكرتارية.إحالة داخلية موثقة.
السكرتاريةتحرر المحاضر والمذكرات وتصدر نسخها، وتحيل الملف للمتابعة.وثيقة محفوظة للطباعة وإحالة للمتابعة.
قسم المتابعةيوثق نتائج النزول والإجراءات مع الجهات المعنية.إعادة النتائج للشؤون الفنية والمالية.
الإدارة الماليةتعتمد كمية المياه والرسوم، وتؤكد سند السداد؛ مسؤول الإسناد فيها يوزع البلاغ المالي.تأكيد دفع؛ لا إغلاق نهائي.
فصل الصلاحيات · المستفيد لا يرى المخالفات أو الملاحظات الداخلية. مسؤول النظام هنا جهة مراجعة وإحالة، ولا يُقصد به تلقائيًا مسؤول الاستضافة.

تعرض النسخة سبعة أدوار للجنة. دور الموظف العام موجود للأعمال المسموحة له، ولا يمنحه إدارة الملفات تلقائيًا. لا توجد حاليًا نافذة مستقلة للإدارة العليا؛ تعرض المتابعة الإدارية للمدير الفني وفق صلاحياته.

01

مسار البلاغ من البداية إلى الإغلاق

المستفيد يرسل البلاغ مباشرة. يحدد النظام القسم، ثم يحدد مسؤول القسم الموظف المنفذ.

بلاغ فني

  1. المستفيد يسجليحفظ محليًا أولًا؛ يتلقى رقمًا مرجعيًا بعد نجاح الرفع.
  2. توجيه للشؤون الفنيةمثل التسريب وضعف المياه وتغير اللون أو الطعم.
  3. المدير الفني يسنديختار فنيًا نشطًا؛ تظهر المهمة لذلك الفني.
  4. الفني يبدأ وينفذيوثق نتيجة المعالجة والصور، ثم يرسلها للمراجعة.
  5. المدير يراجعيعتمد ويغلق، أو يعيد البلاغ لجولة معالجة جديدة.

بلاغ مالي

  1. المستفيد يختار ارتفاع الفاتورةيتجه هذا النوع إلى القسم المالي.
  2. مسؤول القسم المالي يسنديختار المختص المالي المسؤول عن المعالجة.
  3. المختص يبدأ ويعالجيسجل النتيجة ويرسلها للمراجعة.
  4. المدير الفني يراجعيغلق البلاغ أو يعيده للمختص؛ لا يغلقه المختص بنفسه.
التوجيه الحالي · نوع «المبلغ مرتفع في الفاتورة» يتجه للمالية. الأنواع الأخرى تتجه للفنية؛ النص الذي يُكتب ضمن «أخرى» لا يغيّر القسم تلقائيًا.

كيف تقرأ الحالة؟

الحالةالمعنى
مستلم / مسندوصل للخادم، ثم جرى تحديد الموظف المسؤول.
قيد المعالجةبدأ الموظف العمل على المهمة.
بانتظار المراجعة / معادوصلت النتيجة للمدير، أو أعادها لاستكمال المعالجة.
مغلقاعتمد المدير النتيجة؛ يبقى السجل محفوظًا.

02

تشغيل النسخة على Windows

نسخة محلية للكمبيوتر، تعمل دون Docker أو WSL أو آلة افتراضية.

  1. ١
    نزّل الحزمة

    استخدم رابط تحميل النسخة التجريبية من الكمبيوتر. الملف هو WASH-Windows-Portable.zip؛ زر تنزيل مصدر المشروع في GitHub لا يعطي هذه الحزمة الجاهزة.

  2. ٢
    استخرج كل الملفات

    من «التنزيلات»، اضغط بزر الفأرة الأيمن على ZIP واختر «استخراج الكل — Extract All». اختر مجلدًا محليًا قابلًا للكتابة على قرص NTFS؛ تجنب مجلدات الشبكة والمزامنة السحابية.

  3. ٣
    افتح ملف التشغيل

    افتح المجلد المستخرج ثم مجلد WASH-Windows-Portable داخله. شغّل Start.cmd بنقرتين؛ قد يظهر الاسم Start إذا كانت الامتدادات مخفية.

  4. ٤
    انتظر ثم ابدأ التجربة

    يفتح المتصفح دليل الأدوار. اترك نافذة Start مفتوحة أثناء الاستخدام؛ قد يستغرق التشغيل الأول وقتًا أطول لتجهيز قاعدة التجربة.

  5. ٥
    أوقف النسخة بصورة منظمة

    شغّل Stop.cmd. تبقى البيانات والإعدادات محفوظة عند تشغيل Start مرة أخرى.

Start.cmdتشغيل التجربة وفتح المتصفح
Stop.cmdإيقاف هذه النسخة مع حفظ بياناتها
Backup.cmdلقطة كاملة أثناء تشغيل قاعدة النسخة
Restore.cmdاستعادة لقطة إلى حزمة جديدة ونظيفة
المستهدف · Windows 10/11 بنواة 64 بت. لم يُنفذ تشغيل Windows الأصلي في البيئة التي أُعد فيها هذا الدليل؛ تبقى التجربة على جهاز المؤسسة مطلوبة.

أزرار التجربة مخصصة لحسابات خيالية على الكمبيوتر نفسه. هذه النسخة لا تمنح الهاتف رابط إنترنت؛ الوصول عبر الهاتف لاحقًا يحتاج استضافة مؤسسية آمنة.

02

الدخول وتبديل الأدوار في تجربة اللجنة

استعرض الدورة باستخدام أدوار منفصلة بدل منح حساب واحد جميع الصلاحيات.

  1. ١
    اختر شخصية العمل

    اضغط «دخول تجريبي» بجانب الدور الذي تريد اختباره؛ يفتح النظام مساحة ذلك الدور.

  2. ٢
    نفّذ المهمة ثم بدّل الدور

    استخدم «دليل التجربة وتبديل الدور» للعودة. التبديل يغيّر الحساب النشط؛ المسودات والنتائج المحلية تبقى مرتبطة بصاحبها.

  3. ٣
    راقب اختلاف الأدوات

    المستفيد يرى بلاغاته؛ الفني يرى المهام المسندة؛ المدير والمالية والسكرتارية يرون أدوات عملهم فقط.

عند التشغيل المؤسسي · الحسابات الفعلية تستخدم اسم المستخدم وكلمة المرور. المدير الفني يجهز حساب الموظف، والمستفيد ينشئ حساب المستفيدين؛ أزرار دخول اللجنة ليست أسلوب الدخول المؤسسي.

03

تسجيل بلاغ المستفيد

المسار: بوابة المستفيدين ← بلاغ جديد. لا يحتاج المستفيد موظفًا لإدخال بلاغه.

  1. ١
    عرّف المشكلة

    اختر النوع والحي. عند اختيار «أخرى» اكتب الوصف المطلوب في الحقل الإضافي.

  2. ٢
    صف الموقع بدقة

    أدخل العنوان التفصيلي وأقرب معلم؛ تحديد الموقع الجغرافي اختياري.

  3. ٣
    أكمل البيانات

    اسم المبلغ ورقم الهاتف. رقم الاشتراك والعداد إن وجدا؛ ليسا شرطًا لكل بلاغ.

  4. ٤
    أرفق الصور ثم احفظ

    حتى ثلاث صور، لكل صورة حد5 ميجابايت. اضغط «حفظ البلاغ وإرساله»؛ يفحص النظام البيانات ويحفظها محليًا قبل الرفع.

علامة الاستلام · عند نجاح الرفع يظهر رقم مرجعي وحالة البلاغ. وجود عنصر محفوظ على الجهاز وحده لا يعني وصوله للقسم.

بلاغ «وجود ربط مخالف» الذي يقدمه المستفيد يتجه للشؤون الفنية. لا ينشئ تلقائيًا ملف مخالفة مالية؛ تسجيل الضبط الميداني مسار مستقل للفني.

03

متابعة البلاغ والبحث عنه

المستفيد يتابع حالة بلاغه من سجله، ويحتفظ النظام بتاريخه بعد الإغلاق.

ما الذي تبحث عنه؟

رقم البلاغ هو مرجع الرجوع إليه. استخدم أدوات البحث المتاحة في السجل، ثم افتح الملف لمراجعة حالته.

ما الذي يراه المستفيد؟

بلاغاته وحالاتها فقط. لا تظهر له الملاحظات الداخلية أو صور نتائج الموظفين أو ملفات المخالفات.

عند الانقطاع · قد تظهر آخر نسخة محفوظة من بلاغات هذا الحساب على الجهاز. لا تعتبرها حالة لحظية؛ حدّث السجل عند عودة الاتصال.

03

العمل دون اتصال

الحفظ جزء من الصفحات العادية؛ لا توجد نافذة منفصلة بعنوان «العمل بلا إنترنت».

  1. ١
    جهّز الصفحة أولًا

    افتح النظام وسجل الدخول أثناء الاتصال. ولنتيجة التنفيذ، افتح المهمة وابدأ المعالجة حتى تُجهّز بطاقة الجولة على هذا الجهاز.

  2. ٢
    احفظ من الصفحة نفسها

    يسجل المستفيد بلاغًا، ويسجل الفني مخالفة أو نتيجة معالجة وصورها. تبقى العناصر المحفوظة محليًا عند تعذر الرفع.

  3. ٣
    أعد الاتصال بالحساب نفسه

    افتح النظام عندما يتاح الاتصال. يحاول المتصفح الرفع، ويمكن استخدام «محاولة إرسال المحفوظ» لنتيجة التنفيذ.

  4. ٤
    تأكد من الوصول

    راقب رسالة نجاح الرفع ورقم المرجع والحالة. إعادة المحاولة لا تنشئ نتيجة أخرى بالمحتوى نفسه.

إذا تغيرت المهمة · إعادة الإسناد أو بدء جولة جديدة يمنع إرسال نتيجة الجولة القديمة. تبقى النتيجة والصور للمراجعة مع المسؤول.
حدود الحفظ · الإحالات والاعتمادات والسداد والإغلاق النهائي تحتاج اتصالًا. لا يُضمن الرفع والمتصفح مغلق. حذف بيانات المتصفح أو استخدام جهاز آخر قد يفقد العناصر التي لم ترفع بعد.

04

الإسناد إلى المنفذ المسؤول

المسار للمدير: مهام البلاغات ← فتح البلاغ ← اختيار الفني. المالي يسنده مسؤول القسم المالي.

  1. ١
    افتح البلاغ

    راجع النوع والموقع والوصف قبل تحديد المنفذ.

  2. ٢
    حدد الموظف

    اختر فنيًا نشطًا للبلاغ الفني. في البلاغ المالي يختار مسؤول القسم موظفًا ماليًا نشطًا.

  3. ٣
    دوّن ملاحظة الإجراء

    وضح المطلوب، ثم اضغط «إسناد إلى الفني» أو «إسناد إلى المختص المالي» بحسب القسم.

  4. ٤
    تحقق من الإسناد

    يتغير الوضع إلى مسند، وتسجل هوية المسؤول ووقت الإسناد والموظف المختار.

  6. المالية: رسوم وسدادتعتمد الكمية والرسوم، ثم تؤكد سند الدفع.

حفظ البيانات والنسخ والاستعادة

مجلد البرنامج يحتفظ بإعدادات التجربة وقاعدتها ومرفقاتها. لا تحذف بياناته عند تحديث الحزمة.

النسخ

  1. ١
    شغّل النسخة

    يحتاج Backup إلى قاعدة هذه النسخة وهي تعمل.

  2. ٢
    شغّل Backup.cmd

    تُنشأ لقطة مكتملة داخل data/backups، تشمل القاعدة والصور والإعدادات الخاصة.

  3. ٣
    احتفظ بنسخة منفصلة

    انسخ مجلد لقطة مكتملة إلى وسيط آخر محمي. يحتفظ النظام بأحدث سبع لقطات سليمة؛ وجودها على القرص نفسه لا يحمي من فقده.

الاستعادة

  1. ١
    أوقف النسخة القديمة

    احتفظ بمجلدها ونسختها الاحتياطية.

  2. ٢
    استخرج حزمة جديدة

    إلى مجلد آخر نظيف. لا تشغّل Start في النسخة الجديدة أولًا.

  3. ٣
    شغّل Restore.cmd

    أدخل مسار مجلد لقطة كاملة. تُفحص الملفات وتُرفض الاستعادة فوق بيانات قائمة.

  4. ٤

سيناريو عرض وتقييم اللجنة

اختبار عملي محدد النتائج؛ سجّل الملاحظات قبل اعتماد التشغيل المؤسسي.

اختبار البلاغ

  • المستفيد يسجل تسريبًا ببيانات خيالية ويحصل على رقم مرجعي.
  • المدير الفني يسنده؛ الفني يبدأ ويكتب النتيجة ويرفق صورة تجريبية.
  • المدير يعيده مرة مع سبب؛ الفني يكمل جولة جديدة؛ المدير يغلقه.
  • المستفيد يرى الحالة، ولا يرى الملاحظة الداخلية أو صورة التنفيذ.
  • بلاغ ارتفاع الفاتورة يوجه للمالية ويسنده مسؤولها ثم يراجعه المدير.

اختبار المخالفة والتقارير

  • الفني يسجل مخالفة حكومية؛ مسؤول النظام يحيلها للسكرتارية.
  • السكرتارية تصدر مذكرة خيالية؛ المتابعة تعيد نتائج نزول خيالية.
  • المالية تعتمد10.5 م³ وتتحقق من إجمالي 329,200 ريال، ثم تؤكد سندًا وهميًا.
  • المدير يوثق تطبيق السياسة ويغلق؛ محاولة إغلاق المالية ترفض.
  • أضف نموذجًا وعاينه واعتمده ثم أنشئ تقريرًا محفوظًا من نطاق محدد.
  • أوقف خادم التجربة بعد تجهيز الصفحة، واحفظ عنصرًا دون اتصال، ثم أعد Start وتحقق من رفعه مرة واحدة.

الحالةالإجراء المناسب
لم أجد البرنامج بعد التنزيلافتح مجلد التنزيلات، واستخرج ZIP كاملًا، ثم افتح المجلد الداخلي وشغّل Start.
Start لا يفتح النظاماقرأ رسالة نافذة التشغيل. تأكد من Windows x64 ومجلد محلي قابل للكتابة. إذا منعت سياسة جهة العمل التشغيل، ارجع لمختص الجهة.
العنصر محفوظ ولم يظهر في السجلافتح النظام بالحساب نفسه عند الاتصال، ثم تحقق من رسالة المزامنة ورقم المرجع. لا تمسح بيانات المتصفح.
تغير إسناد المهمة أثناء الانقطاعاحتفظ بنتيجتها وصورها المحلية وراجع المسؤول. لا تحاول إدخالها باسم موظف آخر.
لا يظهر زر إجراءراجع الحساب والدور والجهة الحالية وحالة الملف؛ الأدوات مرتبطة بالصلاحية والمرحلة.
حساب الموظف لا يقبل التعطيلانقل مهامه المفتوحة أولًا، وتأكد من بقاء المسؤولين اللازمين.
ملف Word لا يُقبلاستخدم DOCX صالحًا ضمن حدود النموذج، أو أدخل النص يدويًا. الاستيراد للنص لا للتصميم الكامل.
