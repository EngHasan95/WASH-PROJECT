# دليل المستخدم العربي للجنة

دليل مصور من 25 صفحة و22 لقطة شاشة فعلية للنظام. اسم معد النظام في الغلاف وفي بيانات PDF: **حسن القشائي**. الصور لبيانات خيالية في عناقيد تجربة مستقلة، ولا تحتوي قاعدة بيانات أو إعدادات أو كلمات مرور فعلية. لم يُعدّل التطبيق لإنتاج الدليل.

[تحميل دليل PDF النهائي](https://github.com/EngHasan95/WASH-PROJECT/raw/refs/heads/codex/windows-demo-download/downloads/WASH-User-Guide-AR.pdf)

## المخرجات

- `manual.html`: النص والتخطيط القابلان للتعديل.
- `styles.css`: هوية الطباعة A4 من اليمين إلى اليسار، بألوان الأزرق الحبري والفيروزي والنحاسي.
- `assets/`: الخطوط المرخصة وشعار PNG ولقطات الواجهات الأصلية.
- `build_manual.py`: يعيد بناء HTML وPDF ويمنع تجاوز المحتوى للتذييل أو فقد الصور.
- `test-results/WASH-User-Guide-AR.pdf`: النسخة النهائية المحفوظة؛ مستثناة من فرع المصدر.

لإعادة الإخراج في بيئة Codex الحالية:

```bash
python3 docs/user-guide/build_manual.py
```

يستخدم Playwright وChromium وPyMuPDF المثبتة على النظام، وخادم مستند محلي مؤقت فقط. لا يبدأ قاعدة بيانات ولا يغير التطبيق. تُنسخ صور جديدة من `test-results/committee-manual/assets/` إن وجدت؛ الأصول المضمنة تكفي لإعادة بناء الدليل في نسخة مصدر جديدة. تحفظ نتائج الحدود والمعاينات والبصمة في `test-results/committee-manual/`.

الخطوط مضمّنة في PDF والنص قابل للتحديد والبحث. يحتوي الفهرس روابط داخلية، وتضاف علامات مرجعية لكل صفحة، وتُضبط بيانات العنوان والمؤلف. فُحصت صفحات PDF المرندرة، وليس HTML وحده. صورة دليل Windows هي شاشة التطبيق، ولا يُدّعى التقاط شاشة أصلية لنظام Windows.

## المصادر التي روجعت لتنظيم أدلة الشركات العربية

راجعت هذه الموارد الرسمية في7 أكتوبر2026 لأخذ مبادئ التنظيم والشرح، دون نقل صور الشركات أو نصوصها إلى دليل المؤسسة:

- [مركز مساعدة قيود](https://www.qoyod.com/help-center/) و[دليل المعرفة](https://www.qoyod.com/knowledge-base/): فصل موضوعات الإعداد والمهام والتقارير، مع مسار للمستخدم الجديد وأسئلة عملية.
- [ابدأ مع قيود](https://www.qoyod.com/knowledge-base/getting-started/): ترتيب الخطوات الأولى والحالات المتوقعة والأخطاء الشائعة.
- [شرح جعل المهمة خاصة بالموظف في قيود](https://www.qoyod.com/knowledge-base/%d8%ac%d8%b9%d9%84-%d8%a7%d9%84%d9%85%d9%87%d9%85%d8%a9-%d8%ae%d8%a7%d8%b5%d8%a9-%d9%84%d9%84%d9%85%d9%88%d8%b8%d9%81/): وصف إجراء محدد بأسماء الأدوات مع النتيجة التي يراها المستخدم.
- [خدمة العملاء والتدريب في يمن سوفت](https://yemensoft.com/ar-customers-services/): تدريب مرتبط بالصلاحيات والمهام، يجمع معرفة الإجراء وتنفيذه عمليًا وتقييم نتيجة المستخدم. هذه صفحة منهج التدريب، وليست PDF دليل منتج.

موقع دفترة العام يشير إلى دليل الاستخدام في `docs.daftra.com`، لكن ذلك النطاق بقي غير متاح أثناء هذه المهمة. `help.daftra.com` صفحة دخول، ولذلك لم يُعامل على أنه دليل مفتوح. لا يُدّعى مراجعة دليل دفترة التفصيلي.

الهوية والمخططات والنصوص المصورة أُعدت لهذا النظام، مستندة إلى المؤسسة ومساراتها الفعلية. مصدر الصلاحيات والرسوم وحدود الحفظ هو التطبيق والقرارات المعتمدة، وليس أنظمة الشركات الأخرى.

## تحديث الصور

التقط كل صورة من نسخة مستقلة ببيانات خيالية. لا تشغل سيناريو تصوير يغير ملفات اللجنة المحتفظة أو بيانات التطوير. يفرق فهرس التصوير الخاص بين لقطة صفحة ومقتطف عنصر أو نافذة؛ الصورة التجريبية في نموذج التنفيذ ليست صورة إصلاح ميداني حقيقي. عند تغير الواجهة أو مسار العمل، حدّث الصور والنصوص معًا ثم أعد فحص إخراج PDF.

يبقى تشغيل Windows الأصلي وتجربة الهاتف الفعلي واعتماد المؤسسة خارج ما يثبته هذا الدليل. تعليمات التشغيل المحلية والنسخ والاستعادة موجودة فيه دون اشتراكات جديدة أو تغييرات نظام تشغيل.
