# تنزيل وتشغيل النسخة التجريبية على Windows

[تحميل النسخة المختبرة مباشرة — نحو 74 ميجابايت](https://github.com/EngHasan95/WASH-PROJECT/raw/refs/heads/codex/windows-demo-download/downloads/WASH-Windows-Portable.zip)

1. افتح رابط التحميل من الكمبيوتر وانتظر اكتمال ملف WASH-Windows-Portable.zip في مجلد «التنزيلات».
2. انقر الملف بزر الفأرة الأيمن واختر «استخراج الكل» (Extract All). اختر مجلدًا محليًا قابلًا للكتابة على NTFS، مثل WASH-Demo داخل «المستندات».
3. افتح المجلد المستخرج WASH-Windows-Portable وانقر Start.cmd مرتين. لا تشغله من داخل ZIP.
4. اترك نافذة التشغيل مفتوحة. يفتح المتصفح دليل اللجنة وفيه أزرار دخول الأدوار الخيالية للتجربة.
5. للإيقاف استخدم Stop.cmd. للنسخ أثناء التشغيل استخدم Backup.cmd. تعليمات الاستعادة في README.html داخل الحزمة.

المستهدف Windows 10/11 بنواة64بت. لا تحتاج Docker أو Rancher أو WSL أو تثبيت متطلبات على نظام التشغيل. الحزمة للتجربة المحلية ببيانات خيالية. لا تحذف مجلد data بعد التشغيل؛ فيه بيانات التجربة وإعداداتها. الهاتف يستطيع تنزيل ZIP فقط؛ تشغيله يحتاج Windows.

هذه الحزمة هي نسخة 7 أكتوبر 2026 المختبرة في بيئة Linux. لم يُنفذ تشغيل Windows الأصلي في تلك البيئة؛ فحص الملفات لا يثبت اجتياز سياسات جهاز المؤسسة. إذا منعت حماية جهة العمل التشغيل، اطلب مراجعة مختص الجهة ولا تعطل الحماية.

يحتوي هذا الفرع فقط على إضافة حزمة التنزيل ودليلها إلى المصدر المحفوظ. لا يحل فرع التنزيل محل main أو فرع إصلاحات المصدر. يُستخدم ZIP للتشغيل؛ زر Code ثم Download ZIP في GitHub ينزّل المصدر وليس الحزمة الجاهزة.
