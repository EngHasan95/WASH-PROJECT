نسخة Windows المحمولة للتجربة

ابدأ بثلاث خطوات

  1. فك ضغط الحزمة كاملة في مجلد محلي تملك صلاحية الكتابة فيه، مثل مجلد WASH-Demo داخل المستندات. استخدم قرص NTFS على Windows 10 أو 11 بمعمارية x64؛ يفضّل مسار قصير. لا تشغّل من داخل ZIP أو مجلد شبكة أو مجلد تزامن سحابي.
  2. انقر مرتين على Start.cmd. في التشغيل الأول يجهّز البرنامج قاعدة تجريبية مستقلة، ثم يفتح دليل اللجنة في متصفحك.
  3. اختر الدور الذي تريد تجربته. اترك نافذة Start مفتوحة أثناء العمل. للإيقاف استخدم Stop.cmd، أو Ctrl+C داخل نافذة Start، وانتظر تأكيد توقف البرنامج.

الحزمة تضم Python وPostgreSQL والمكتبات والخطوط والصور. لا تحتاج Docker أو Rancher أو WSL أو آلة افتراضية أو حسابًا خارجيًا. لا تثبّت خدمة، ولا تغيّر سجل Windows أو إعدادات الجدار الناري أو PATH العام، ولا تطلب تشغيلًا بصلاحية مدير. تعمل البرامج كعمليات عادية داخل مجلد النسخة. المتصفح الحالي وWindows هما المتطلبات.

إذا منعت سياسة جهة العمل تشغيل البرامج المحمولة، أرسل نص الرسالة لمسؤول تقنية المعلومات؛ لا تعطل حماية Windows أو تتجاوز سياسة المؤسسة.

أين بياناتي؟

ينشأ مجلد data عند أول تشغيل، ويحتوي قاعدة التجربة والصور والإعدادات الخاصة والنسخ الاحتياطية. يحميه البرنامج بصلاحيات حساب Windows الحالي وSYSTEM على NTFS. لا تحذفه ولا تنقل نسخة أحدث فوقه عشوائيًا، ولا تشارك ملف data/settings.json. إغلاق النظام وإعادة تشغيله يحافظان على نتائجك، وإعادة الضغط على Start أثناء التشغيل تفتح النسخة الحالية.

لعمل نسخة احتياطية شغّل Backup.cmd أثناء تشغيل النظام. تجد النسخ تحت data/backups؛ توجد أيضًا نسخة تلقائية عند الحاجة وكل 24 ساعة أثناء التشغيل. تحتوي اللقطة الكاملة أيضًا إعدادات القاعدة ومفتاح Django وحسابات اللجنة؛ كلها ملفات خاصة غير مشفرة، فلا تشاركها علنًا. يحتفظ البرنامج بأحدث سبع لقطات مكتملة ويتحقق من المساحة قبل النسخ، ويعرض فشله في نافذة Start وملف data/backup.log. احتفظ بنسخة على وسيط مأذون ومحمي لدى المؤسسة؛ النسخة على القرص نفسه لا تحمي من تلفه.

ما الذي تستطيع تجربته؟

نفس واجهات النظام وبيانات اللجنة الخيالية: المستفيد، المدير الفني، الفني، مسؤول النظام، السكرتارية، المتابعة والمالية. مسارات البلاغات والمخالفات، الصلاحيات، النماذج والطباعة والرسوم لم تتغير. الحكومي مثل التجاري: 325,000 ريال + 400 لكل متر مكعب. المنزلي: 225,000 ريال + 300 لكل متر مكعب. المالية تؤكد السداد والمدير الفني يغلق بعد المعالجة.

الدخول التجريبي متاح على هذا الكمبيوتر فقط، بحسابات خيالية. لا تستخدم هذه الحزمة لبيانات المؤسسة الحقيقية أو تعرضها على الإنترنت. استخدم ملفي متصفح مستقلين إذا أردت اختبار دورين بالتوازي؛ التبويبان داخل الجلسة نفسها يشتركان في الحساب.

الحفظ عند الانقطاع والهاتف

بعد فتح نموذج تقديم البلاغ أو المخالفة مرةً أثناء التشغيل، يمكنك إيقاف النظام، تسجيل بيانات تجريبية في النموذج ثم إعادة تشغيله لمزامنتها. فصل الإنترنت وحده لا يوقف الخادم المحلي؛ لا توجد حاجة لإنترنت بعد فك الحزمة. لا تحذف بيانات المتصفح وفيها عناصر لم تُرفع.

هذه النسخة تفتح على الكمبيوتر الذي يشغّلها فقط. الوصول من الهاتف يحتاج نشرًا منفصلًا عبر HTTPS بصلاحيات دخول فعلية؛ لا تستخدم أزرار الأدوار التجريبية للنشر العام.

استعادة نسخة كاملة

أوقف النسخة الأصلية، وفك الحزمة في مجلد جديد دون تشغيل Start. شغّل Restore.cmd وأدخل مسار مجلد اللقطة المكتملة. يفحص الملفات ويستعيد القاعدة والصور والإعدادات، ثم شغّل Start. يرفض البرنامج استبدال أي بيانات موجودة أو تغيير المنافذ بصمت؛ لا تحذف النسخة الأصلية أو اللقطة. إذا فشلت الاستعادة احتفظ بالمجلد للتشخيص وأعدها إلى نسخة نظيفة أخرى. اللقطات القديمة التي لا تشمل metadata تحتاج استعادة تقنية.

حدود الاختبار

راجع ملف VALIDATION.txt لمعرفة الاختبارات المنفذة فعليًا. التشغيل الأصلي على جهاز Windows لم يُتحقق منه في بيئة البناء Linux. راجع تقارير المرحلة الحالية داخل app/docs لمعرفة الإصلاحات والقيود؛ نجاح اختبارات السحابة لا يعني تنفيذ اختبار Windows أصلي.

إذا توقف Start بخطأ، أبقِ النافذة مفتوحة وانسخ رسالة الخطأ فقط. لا ترسل الإعدادات الخاصة أو قاعدة البيانات. إذا فُقدت الإعدادات الأصلية مع وجود قاعدة، يرفض البرنامج إعادة إنشائها لحماية النتائج؛ يلزم استرجاعها من النسخة الأصلية.

برامج مفتوحة المصدر وتراخيصها محفوظة داخل الحزمة. لا يُطلب اشتراك أو تثبيت على مستوى نظام التشغيل.
